# PI Remote Control (`local.pi-remote-app`)

端到端加密（X25519 + HKDF-SHA256 + AES-256-GCM）的 PI-Desktop 远程控制插件，与配套移动 App 和开源零知识盲中继协同工作。

## 特性
- **零信任配对**：120 秒单次配对码 + 双端 6 位核验短码（SAS）人工确认，桌面可随时吊销单台设备。
- **双路径连接**：支持局域网 / Tailscale 直连低延迟模式，以及自托管开源盲中继（中继仅转发密文信封）。
- **原生编程控制体验**：项目/会话切换、实时流式吐字与工具状态（基于 `agentExtensions` 回环桥）、只读 Git Unified Diff（含工作区根边界校验与凭据黑名单）、一键急停。
- **双模式审批兼容**：
  - **标准模式（默认）**：严格遵守 PI-Desktop 原生桌面高危弹窗，手机端展示完整待审批上下文并标明“需桌面确认”。
  - **完整无人值守模式（可选）**：用户主动使用 `PI_DESKTOP_MCP_CONTROL=1` 启动 PI-Desktop 后，自动接入本机 `127.0.0.1` 回环控制面，支持手机端直接批准工具权限 / AskTool / Plan。
